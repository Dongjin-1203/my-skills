# 입력 대조 절차

제작 전에 무엇이 합의되었고 무엇이 비어 있는지 가려내는 단계다. 여기서 대충 넘기면 제작 뒤에 "이건 합의한 적 없다"는 되돌림이 생기므로, 모든 판단은 지시문의 실제 문장에 근거한다.

## 1. 입력

| 입력 | 필수 | 못 찾았을 때 |
|---|---|---|
| 제작 지시문 | 필수 | 강사에게 붙여넣기 또는 첨부를 요청 |
| 블록별 조사 결과(`조사/B01_….md` 등) | 지시문의 '조사 채택 목록'이 가리키는 경우 | 그 조사에 의존하는 설명·사례·활동 부분만 보류하고 `curriculum-to-lesson`으로 조사를 요청하도록 안내. 사실을 새로 채우지 않는다 |
| 과정 공통 기준(기관 지침, 스타일 가이드) | 지시문이 가리키는 경우 | 지시문 안의 기준만 쓴다. 접근 불가 표시 |
| 원본 커리큘럼·시간표 | 지시문이 가리키는 경우 | 시간·범위 대조만 보류 |
| 제공 자료(읽기 자료, 데이터, 이미지)·지정 템플릿 | 지시문이 가리키는 경우 | 그 자료에 의존하는 부분만 보류 |

설계 단계 도구의 원문 대화는 입력이 아니다. 지시문이 인용한 내용은 지시문에 적힌 대로만 쓴다.

## 2. 최신 합의 찾기

1. 지시문 안의 버전, 날짜, 변경 이력, "보정", "우선" 같은 표기를 먼저 찾는다.
2. 뒤의 내용이 앞을 대체한다고 **명시된 경우에만** 최신 합의로 쓴다. 명시가 없으면 충돌로 분류한다.
3. 지시문과 다른 문서(커리큘럼, 기관 지침)가 어긋나면 어느 쪽이 우선인지 문서에 적혀 있는지 본다. 적혀 있지 않으면 충돌이다.

## 3. 운영 조건 대조

수강생 수준·직무·인원, 사용할 도구와 계정 필요 여부(수강생이 AI 도구를 쓰는 수업인지 포함), 수업 방식(대면·온라인), 한 회차 길이, 실습·활동 환경을 지시문과 대조한다. 조건이 지시문에 없으면 "미확인"으로 두고, 그 조건에 의존하는 제작 항목만 보류한다. 수준 정보가 없을 때 입문 수준으로 가정할 수 있지만 가정이라고 표시한다.

## 4. 블록 매핑

지시문의 블록(차시·주제 단위)마다 아래 표를 채운다. 별도 파일로 저장하지 않고 제작·검증에 쓴다. 작업 결과 기록에는 요약만 옮긴다.

| 블록 | 목표 | 필수 설명 | 사례·시연 | 활동(토론·실습·과제) | 시간 | 산출물 | 완료 기준 | 상태 | 반영 위치 |
|---|---|---|---|---|---|---|---|---|---|

- 상태: `확정` / `누락` / `충돌` / `미결정`.
- 반영 위치: 제작 뒤 슬라이드 번호(표시 순서)나 활동 번호를 적는다. 검증에서 합의 반영 여부를 확인할 때 쓴다.
- 지시문에 없는 칸은 비워 두고 `누락`으로 표시한다. 그럴듯한 값을 넣지 않는다.

### 조사 결과의 사용 규칙

- 지시문의 '조사 채택 목록'에서 `채택`·`수정`인 항목만 사실 근거로 쓴다. `보류` 항목과 확인 수준이 `기억 기반·미확인`인 항목은 쓰지 않는다.
- 블록 카드의 '사용할 조사'에 적힌 항목은 해당 블록의 설명·사례·활동에 반영하고, 반영 위치(슬라이드 번호·활동 번호)를 블록 매핑의 '반영 위치'에 적는다.
- 슬라이드·수강생 자료의 출처 표기는 조사 파일의 출처 목록에 있는 제목과 URL(서지 정보)을 그대로 쓴다.
- 조사 보고서를 그대로 복사하지 않는다. 학습목표에 맞는 설명·사례·활동으로 바꿔 쓰되 사실·수치·인용은 조사 파일과 일치하게 유지한다.
- 조사 파일에 `교육용 창작`으로 구분된 사례는 가상 사례로 표시한다.
- 조사 파일에 없는 사실을 새로 넣어야 하면 쓰지 말고 '남은 판단'에 올려 조사를 추가하도록 한다. 지시문과 조사 결과가 충돌하면 충돌로 분류한다.

## 5. 질문 규칙

- 작업에 필요한 항목만 묻는다. 지시문에 이미 답이 있는 것, 제작 결과에 영향이 없는 것은 묻지 않는다.
- 한 번에 묶어서 묻고, 항목마다 선택지와 제안 기본값을 붙인다. 제안 기본값은 강사가 고르기 전까지 확정이 아니다.
- 보류는 블록 전체가 아니라 **그 항목에 의존하는 부분**만 한다. 시간 충돌처럼 여러 블록에 걸친 항목은 시간에 의존하는 표기·배분만 보류하고 나머지는 계속 만든다.
- 강사에게 바로 물을 수 없는 상황(자동 실행 등)이면 질문 대신 보류 목록으로 남기고 가능한 범위까지 만든다.

### 무엇을 만들고 무엇을 묻는가

합의 사항 자체와, 합의한 산출물을 채우는 내용은 다르다. 앞의 것을 지어내면 강사의 결정을 대신하게 되고, 뒤의 것까지 전부 물으면 제작이 멈춘다.

| 항목 | 처리 |
|---|---|
| 산출물을 구성하는 예시·가상 사례·모범 답안·표의 열 구성 중 지시문이 값을 정하지 않은 것 | 직접 만들고 "창작 예시"로 표시한다. 보고의 '남은 판단'에 올리며, 이것 때문에 제작을 멈추지 않는다 |
| 지시문이 "제공된/주어진"이라고 쓴 실제 자료(논문, 기사, 데이터, 이미지 등) | 강사 자료다. 내용을 받지 못했으면 요청하고 만들어 넣지 않는다. 강사가 만들라고 하면 창작 표시를 붙여 만든다 |
| 학습목표, 시간 배분, 수강생 수준, 사용 도구·계정, 실제 사실·통계·인용·출처·판례·이론의 원문 | 지시문에 없으면 임의로 확정하지 않는다. 묻는다 |
| `[미결정]` 표기 | 안전한 기본 처리가 있고 결과에 영향이 작으면 질문 없이 진행하고 "확인 필요"로 보고한다(예: 발표자 노트 공개 여부 미결정 → 노트에는 수강생에게 보여도 되는 내용만). 영향이 크면 묻는다 |
| 지시문에 항목 자체가 없음(예: 블록 2에 사례 항목이 없음) | 의도적 생략으로 읽고 만들지 않는다. 보고에 한 줄 남긴다 |

인문·사회·경영 자료에서는 **인용문, 통계, 연구 결과, 법·제도 조항, 기업 사례의 수치**를 AI가 기억에 의존해 쓰면 틀릴 위험이 크다. 지시문이나 강사 자료에 없는 사실 정보는 쓰지 않거나, 쓰더라도 "확인 필요"로 표시한다.

## 6. 분야별 맞춤 기준

SKILL.md 단계 0에서 받은 분야 답변으로 아래 표의 해당 행을 채워 제작에 쓴다. 표에 없는 분야는 가장 가까운 행을 기준으로 하고 강사가 말한 용어·방식을 우선한다. 표의 내용은 기본값이며 지시문과 강사의 답이 우선한다.

| 분야 | 사례·자료 유형 | 근거·출처 | 활동 형식 | 특히 주의 |
|---|---|---|---|---|
| 인문(철학·문학·역사·언어) | 원문 발췌, 텍스트 읽기, 연표, 개념 지도 | 저자·판본·쪽수. 번역서는 역자 표기 | 텍스트 정독, 논증 재구성, 토론, 에세이 | 원문 인용은 짧게·정확히. 번역·해석 차이를 구분 |
| 사회(심리·사회·교육·정치·법) | 연구 결과, 사례 연구, 통계 자료, 조항·판례 | 연구자·연도·표본, 법 조항 번호, 통계 기준 연도 | 사례 분석, 토론, 설문 설계, 정책 비교 | 통계·판례·조항은 AI 기억으로 쓰지 않는다. 관점 균형 |
| 경영(경영·마케팅·회계·인사) | 기업 사례, 재무제표, 시장 데이터, 프레임워크(SWOT 등) | 기업 공시·보고서·기사 출처와 기준 시점 | 케이스 분석, 프레임워크 적용, 의사결정 시뮬레이션, 보고서 | 실제 기업 수치는 확인된 자료만. 가상 사례는 가상 표시 |
| 기타 | 강사 답변에 따름 | 강사 답변에 따름 | 강사 답변에 따름 | |

## 7. 분류 예

| 상황 | 분류 | 처리 |
|---|---|---|
| 활동 2에서 쓸 도구가 지시문에 없다 | 누락 | 활동 2만 보류하고 질문 |
| 시간이 지시문 본문은 50분, 표에는 45분 | 충돌 | 어느 쪽인지 질문. 다른 블록은 진행 |
| 발표자 노트 공개 정책이 `[미결정]` | 미결정 | 노트는 수강생에게 보여도 되는 내용만 쓰고, 정책 확인 필요로 보고 |
| 첨부한 템플릿 파일이 열리지 않는다 | 접근 불가 | 템플릿 의존 단계만 보류 |
| "제공된 사례 기사"라고만 있고 내용이 없다 | 누락(강사 자료) | 내용을 요청. 그 기사에 의존하는 활동 부분만 보류 |
| 지시문이 언급한 조사 메모가 없다 | 접근 불가 | 접근 불가로 표시. 출처로 쓰지 않는 자료면 제작에는 영향 없음 |
